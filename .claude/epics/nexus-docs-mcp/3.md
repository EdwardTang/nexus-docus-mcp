# Task: Document Ingestion & RAG Pipeline

## Description
Implement the complete RAG (Retrieval-Augmented Generation) pipeline: parse qumulo-docs.txt, chunk with LangChain, generate embeddings with OpenAI, store in ChromaDB, and establish citation mapping to docs.qumulo.com.

## Acceptance Criteria
- [ ] qumulo-docs.txt parser extracts sections, metadata (version, category, URLs)
- [ ] RecursiveCharacterTextSplitter chunks documents (1024 tokens, 128 overlap)
- [ ] OpenAI embedding generation (text-embedding-3-small) with batch processing (100/batch)
- [ ] ChromaDB integration stores embeddings with metadata (section, version, url, category)
- [ ] Citation mapping links chunks to docs.qumulo.com URLs with section context
- [ ] Indexing script (`npm run index-docs`) processes qumulo-docs.txt successfully
- [ ] Vector database persists to disk for reuse across server restarts
- [ ] Indexing metrics logged (total chunks, documents processed, time taken)

## Technical Details
**Implementation Approach:**
- Use LangChain's `RecursiveCharacterTextSplitter` for semantic chunking
- Implement document parser to extract sections from qumulo-docs.txt (assumes Markdown structure)
- Batch embed chunks using OpenAI API with rate limiting and retry logic
- Store in ChromaDB with metadata schema: `{section, version, url, category, chunk_index, total_chunks}`
- Generate docs.qumulo.com URLs from section titles (configurable URL template)

**Key Files:**
- `src/rag/parser.ts` - Document parsing logic
- `src/rag/chunker.ts` - Text chunking with LangChain
- `src/rag/embedder.ts` - OpenAI embedding generation
- `src/rag/vectorstore.ts` - ChromaDB client and storage
- `src/rag/citation.ts` - Citation mapping and URL generation
- `scripts/index-docs.ts` - CLI script for indexing

**Code Locations:**
- Document parsing: `src/rag/parser.ts`
- Embedding pipeline: `src/rag/embedder.ts`
- Vector storage: `src/rag/vectorstore.ts`
