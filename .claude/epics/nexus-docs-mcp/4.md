# Task: Search Docs MCP Tool Implementation

## Description
Implement the `search_docs` MCP tool with semantic search, vector similarity matching, optional reranking, and citation generation linking to docs.qumulo.com.

## Acceptance Criteria
- [ ] MCP tool `search_docs` registered with proper input schema (query, filters, limit)
- [ ] Query embedding generation using same OpenAI model as indexing
- [ ] Vector similarity search in ChromaDB (k=5-10, cosine similarity >0.7)
- [ ] Optional cross-encoder reranking for improved relevance
- [ ] Version and category filtering support
- [ ] Citation generation with relevance scores and docs.qumulo.com URLs
- [ ] Response formatted for chatbot display with markdown support
- [ ] Query response time p95 < 500ms (excluding network latency)

## Technical Details
**Implementation Approach:**
- Register `search_docs` tool in MCP tool registry
- Implement query embedding with caching (LRU cache for recent queries)
- Vector search with configurable similarity threshold and result limit
- Optional reranking using cross-encoder model (if performance allows)
- Format results with citations: URL, section title, relevance score, snippet

**Input Schema:**
```typescript
{
  query: string;           // Required: search query
  filters?: {
    version?: string;      // e.g., "7.2.5"
    category?: string;     // e.g., "API", "Troubleshooting"
  };
  limit?: number;          // Default: 5, max: 20
}
```

**Key Files:**
- `src/tools/search-docs.ts` - Main tool implementation
- `src/rag/search.ts` - Vector search logic
- `src/rag/rerank.ts` - Optional reranking (cross-encoder)
- `src/utils/cache.ts` - Query embedding cache

**Code Locations:**
- Tool handler: `src/tools/search-docs.ts`
- Search logic: `src/rag/search.ts`
- Citation formatting: `src/rag/citation.ts`
