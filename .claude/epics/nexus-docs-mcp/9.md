# Task: Production Deployment & Monitoring

## Description
Set up production deployment infrastructure with Kubernetes manifests, Docker images, CI/CD pipeline, horizontal pod autoscaling, and comprehensive monitoring/observability using Prometheus and Grafana.

## Acceptance Criteria
- [ ] Dockerfile for MCP server with multi-stage build (TypeScript compilation)
- [ ] Kubernetes deployment manifests (Deployment, Service, HPA, ConfigMap, Secret)
- [ ] Horizontal Pod Autoscaler configured (3-10 pods, 70% CPU / 80% memory thresholds)
- [ ] Health probes configured (liveness on `/health`, readiness on `/ready`)
- [ ] Docker Compose for local development (MCP server + ChromaDB + Redis + chatbot)
- [ ] CI/CD pipeline (GitHub Actions) for automated testing and deployment
- [ ] Prometheus metrics exposed (query latency, tool invocations, cache hit rate, error rate)
- [ ] Grafana dashboards for system monitoring (query metrics, telemetry integration, vector search performance)
- [ ] Alerting rules for error rate spikes, latency degradation, telemetry API failures
- [ ] Production rollout plan with staged deployment (staging → beta → production)

## Technical Details
**Implementation Approach:**
- Multi-stage Dockerfile: build stage (TypeScript compilation) + runtime stage (Node.js slim)
- Kubernetes manifests for MCP server, Qdrant (or ChromaDB), Redis cluster
- HPA based on CPU and memory utilization with custom metrics (query rate)
- Prometheus client library for metrics export (prom-client for Node.js)
- Grafana dashboards with panels for: query latency histogram, tool invocations counter, cache hit rate gauge, error rate by tool
- CI/CD pipeline: lint → test → build Docker image → deploy to staging → run smoke tests → deploy to production

**Kubernetes Resources:**
```yaml
# Deployment with 3 replicas
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nexus-docs-mcp
spec:
  replicas: 3
  # ... HPA, health probes, resource limits

# Service for load balancing

kind: Service
metadata:
  name: nexus-docs-mcp
spec:
  type: ClusterIP
  # ... port configuration

# HorizontalPodAutoscaler
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: nexus-docs-mcp-hpa
spec:
  minReplicas: 3
  maxReplicas: 10
  # ... CPU/memory targets
```
