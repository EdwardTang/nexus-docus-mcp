# Task: Nexus Chatbot MCP Client Integration

## Description
Integrate MCP client into Nexus chatbot platform to connect with the MCP server, implement query routing logic, and render responses with citations and telemetry visualizations.

## Acceptance Criteria
- [ ] MCP client SDK integrated in Nexus chatbot codebase
- [ ] Client connects to MCP server via stdio/HTTP/SSE transport
- [ ] Query intent analysis determines which MCP tools to invoke (search_docs, get_telemetry, etc.)
- [ ] Parallel tool invocation for independent queries (docs + telemetry)
- [ ] Response synthesis combines results from multiple tools
- [ ] Citation rendering with clickable links to docs.qumulo.com
- [ ] Telemetry visualization: charts for metrics, colored alerts by severity
- [ ] Error handling with user-friendly messages when MCP server unavailable
- [ ] End-to-end user flow: query → MCP tools → formatted response

## Technical Details
**Implementation Approach:**
- Use `@modelcontextprotocol/sdk/client` for MCP protocol handling
- Implement query analyzer to extract intent (cluster ID, API endpoint, issue symptoms)
- Route to appropriate tools: search_docs (always), get_telemetry (if cluster mentioned), analyze_api (if API mentioned), diagnose_issue (if problem described)
- Execute tools in parallel where possible using `Promise.all()`
- Format responses: markdown for text, charts for telemetry, linked citations

**Query Routing Logic:**
```typescript
// Always search docs
tools.push({ name: "search_docs", arguments: { query } });

// If cluster mentioned
if (hasClusterId(query)) {
  tools.push({ name: "get_telemetry", arguments: { clusterId, metrics } });
}

// If API mentioned
if (hasApiEndpoint(query)) {
  tools.push({ name: "analyze_api_call", arguments: { apiEndpoint } });
}

// If issue symptoms
if (hasIssueSymptoms(query)) {
  tools.push({ name: "diagnose_issue", arguments: { clusterId, symptoms } });
}
```

**Key Files:**
- `src/mcp/client.ts` - MCP client initialization and connection

- `src/mcp/synthesizer.ts` - Response synthesis and formatting
- `src/ui/citations.tsx` - Citation rendering component

**Code Locations:**
