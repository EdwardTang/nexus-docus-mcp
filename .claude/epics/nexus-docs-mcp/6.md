# Task: Get Telemetry & Diagnose Issue MCP Tools

## Description
Implement `get_telemetry` MCP tool for real-time cluster metrics retrieval and `diagnose_issue` tool that correlates telemetry anomalies with troubleshooting documentation.

## Acceptance Criteria
- [ ] `get_telemetry` MCP tool registered with input schema (clusterId, metrics, timeRange)
- [ ] Fetches metrics from Redis cache (fallback to live API if cache miss)
- [ ] Formats telemetry data for chatbot display (charts, tables, alerts)
- [ ] Trend analysis: identify increasing/decreasing/stable patterns
- [ ] `diagnose_issue` tool correlates telemetry anomalies with documentation
- [ ] Anomaly detection: high latency, capacity warnings, node failures
- [ ] Search troubleshooting docs based on detected anomalies
- [ ] Response includes telemetry snapshot + related documentation with citations

## Technical Details
**Implementation Approach:**
- `get_telemetry` fetches from Redis cache, falls back to Qumulo API if stale
- Format metrics for display: capacity as percentage, performance with trends, alerts with severity
- `diagnose_issue` extracts symptoms from query, fetches current telemetry, detects anomalies
- Search documentation with anomaly-based keywords (e.g., "high latency troubleshooting")
- Combine telemetry data with docs in structured response

**get_telemetry Input Schema:**
```typescript
{
  clusterId: string;                          // Required
  metrics: string[];                          // ["capacity", "performance", "health", "alerts"]
  timeRange?: string;                         // "1h", "24h", "7d"
}
```

**diagnose_issue Input Schema:**
```typescript
{
  clusterId: string;                          // Required
  symptoms: string;                           // User-described issue
  includeHistory: boolean;                    // Include historical patterns
}
```

**Key Files:**
- `src/tools/get-telemetry.ts` - Telemetry retrieval tool
- `src/tools/diagnose-issue.ts` - Diagnostic tool
- `src/telemetry/anomaly.ts` - Anomaly detection logic
- `src/telemetry/formatter.ts` - Telemetry formatting for display

**Code Locations:**
- Tool handlers: `src/tools/get-telemetry.ts`, `src/tools/diagnose-issue.ts`
- Anomaly detection: `src/telemetry/anomaly.ts`
- Correlation logic: `src/tools/diagnose-issue.ts`
