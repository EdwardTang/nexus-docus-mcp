# Task: API Documentation Tool

## Description
Implement `analyze_api_call` MCP tool that maps Qumulo API endpoints to documentation, provides parameter/schema details, version compatibility tracking, and code examples in Python/JavaScript/cURL.

## Acceptance Criteria
- [ ] `analyze_api_call` MCP tool registered with input schema (apiEndpoint, version, includeExamples)
- [ ] Maps API endpoints to relevant documentation sections
- [ ] Extracts parameters, request/response schemas, and descriptions
- [ ] Version compatibility tracking (introduced/deprecated/removed in versions)
- [ ] Code example generation for Python, JavaScript, cURL
- [ ] Response includes endpoint docs, schemas, examples, version info
- [ ] Suggests alternative endpoints if deprecated/removed
- [ ] Search documentation for API-related content using RAG engine

## Technical Details
**Implementation Approach:**
- Parse API endpoint from query (e.g., `/v1/cluster/capacity`)
- Search documentation for API-specific sections using RAG with category filter "API"
- Extract structured info: parameters, schemas, version availability
- Generate code examples using templates for common languages
- Track version compatibility from documentation metadata

**analyze_api_call Input Schema:**
```typescript
{
  apiEndpoint: string;                        // Required: API path (e.g., "/v1/cluster/capacity")
  version?: string;                           // Optional: Qumulo version (e.g., "7.2.5")
  includeExamples: boolean;                   // Include code examples (default: true)
}
```

**Response Structure:**
```typescript
{
  endpoint: string;
  description: string;
  parameters: Parameter[];
  requestSchema: JSONSchema;
  responseSchema: JSONSchema;
  examples: CodeExample[];                    // Python, JavaScript, cURL
  versionInfo: {
    introducedIn: string;                     // "7.0.0"
    deprecatedIn?: string;                    // "8.0.0"
    removedIn?: string;                       // "9.0.0"
    alternatives?: string[];                  // Suggested replacements
  };
  relatedDocs: Citation[];
}
```

**Key Files:**
- `src/tools/analyze-api.ts` - API analysis tool
- `src/api/parser.ts` - API documentation parser
- `src/api/examples.ts` - Code example generator
- `src/api/versions.ts` - Version compatibility tracker

**Code Locations:**
- Tool handler: `src/tools/analyze-api.ts`
- API parsing: `src/api/parser.ts`
- Example generation: `src/api/examples.ts`
