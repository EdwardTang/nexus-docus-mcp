# Task: MCP Server Foundation Setup

## Description
Set up the Node.js/TypeScript project foundation with MCP SDK integration, including project structure, dependencies, MCP protocol handlers, and basic health endpoints.

## Acceptance Criteria
- [ ] Node.js 20+ project initialized with TypeScript configuration
- [ ] `@modelcontextprotocol/sdk` installed and configured
- [ ] MCP server implements JSON-RPC 2.0 protocol handlers (stdio/HTTP/SSE)
- [ ] Tool registry framework implemented for dynamic tool registration
- [ ] Resource manager skeleton for URI-based resource access
- [ ] Health endpoints (`/health`, `/ready`) implemented and responding
- [ ] Basic error handling and logging framework in place
- [ ] Development environment runs locally with `npm run dev`

## Technical Details
**Implementation Approach:**
- Initialize Node.js project with TypeScript, ESLint, Prettier
- Install core dependencies: `@modelcontextprotocol/sdk`, Express/Fastify for HTTP endpoints
- Create `src/index.ts` as main entry point with MCP server initialization
- Implement tool registry pattern for registering MCP tools dynamically
- Set up stdio transport for MCP client communication
- Add health check endpoints for Kubernetes probes

**Key Files:**
- `package.json` - Dependencies and scripts
- `tsconfig.json` - TypeScript configuration
- `src/index.ts` - Main server entry point
- `src/server.ts` - MCP server setup and configuration
- `src/tools/registry.ts` - Tool registration framework
- `src/resources/manager.ts` - Resource access manager
- `src/utils/logger.ts` - Logging utility

**Code Locations:**
- MCP server initialization: `src/server.ts`
- Protocol handlers: `src/handlers/` directory
- Health endpoints: `src/health.ts`
